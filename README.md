# Simulador de Financiamento Imobiliário

API desenvolvida em C# com .NET 9 e Entity Framework Core para simular financiamentos residenciais seguindo regras reais do mercado brasileiro.

## Funcionalidades
- Cadastro e consulta de imóveis
- Cálculo de financiamento (em desenvolvimento)
- Validação de dados do usuário e do imóvel
- Integração com banco de dados MySQL

## Tecnologias utilizadas
- C# + .NET 9
- ASP.NET Core Web API
- Entity Framework Core
- MySQL
- Swagger

## Como executar

```bash
dotnet restore
dotnet run
